# ⚡ TELEMETRIA (`tlm`)

**Повноцінний CLI / TUI застосунок для моніторингу всіх комплектуючих ПК, реального споживання електроенергії з розетки (AC Wall Power), автооновлення тарифів та курсів валют з інтернету, а також розрахунку рентабельності майнінгу та здачі ПК в оренду як GPU/AI-сервера.**

## 🎯 Чому створено Telemetria? (Дослідження GitHub аналогів)

Перед розробкою було проведено дослідження існуючих рішень на GitHub через `gh` CLI:
- **`GIN-SYSTEMS/vigil-tui`** — термінальний монітор потужності CPU/GPU, проте він має лише статичну ціну кВт·год у конфігу, **не підтримує автооновлення тарифів та курсів валют з інтернету**, не враховує двозонні/тризонні лічильники (День/Ніч), не моделює ККД блоку живлення (80 PLUS) і не має режиму розрахунку окупності оренди сервера чи майнінгу.
- **`naveenkul/WattWise`** — вимагає фізичних розумних розеток TP-Link Kasa або сервера Home Assistant.
- **`btop` / `nvtop` / `s-tui` / `toppy` / `spark-smi`** — чудові монітори завантаження ресурсів, але не ведуть фінансового обліку спожитої електроенергії, вартості роботи за сесію/місяць та рентабельності GPU-ноди.

**Telemetria** об'єднує глибоку апаратну телеметрію рівня `NVML / RAPL / WMI` з фінансовим та енергетичним аналізатором у реальному часі.

## ✨ Ключові можливості

### 1. 🖥 Повна технічна телеметрія комплектуючих ПК
- **Процесор (CPU)**: модель, загальне та потокове навантаження (`%`), поточна і буст-частота (`MHz`), температура (`°C`), споживання пакету (`W` та `% від TDP`), детекція тротлінгу. Калібровані профілі для сучасних процесорів включно з **AMD Ryzen 7 7800X3D / 9800X3D / 7950X** та **Intel Core**.
- **Відеокарта (GPU)**: прямий доступ через C-API **NVIDIA NVML (`pynvml`)** та фолбек `nvidia-smi` (<1 мс на опитування без потреби прав адміністратора):
  - Точна температура ядра (`°C`), оберти кулерів (`%`, включно з режимом *Zero-RPM Fan Stop*),
  - Реальне енергоспоживання у Ватах з точністю до мілівата (`power.draw` / `power.limit`),
  - Апаратний лічильник спожитої енергії відеокарти (`Total Energy Consumption` у кВт·год),
  - Завантаження GPU та контролера пам'яті, зайнята/доступна відеопам'ять **VRAM (`MiB`)**,
  - Частоти ядра та пам'яті (`MHz`), стан живлення (`P0`–`P8`), лінк `PCIe Gen / Width`.
- **Оперативна пам'ять (RAM)**: обсяг зайнятої/доступної ОЗП та Swap, автоматичне визначення фізичних модулів DIMM (кількість планок, тип `DDR5`/`DDR4`, частота `MT/s`, парт-номер) та розрахунок їхнього споживання у Ватах.
- **Накопичувачі (NVMe / SSD / HDD)**: модель фізичного диска, статус здоров'я (`Healthy`), зайнятий простір розділів, швидкість читання/запису в реальному часі (`MB/s`) та оцінка споживання (`W`).
- **Мережа (Network)**: активний інтерфейс, поточна швидкість завантаження/відвантаження (`↓↑ MB/s`), сумарний трафік за сесію (`GB`).
- **Топ енергоємних процесів**: ранжування процесів ОС за розрахунковим споживанням енергії (`W`) та їхньою вартістю у гривнях на добу (`₴/доба`).

### 2. 🔌 Розрахунок реального споживання з розетки (AC Wall Power)
Більшість утиліт показують лише DC-споживання чіпа CPU або GPU. **Telemetria** рахує повний енергетичний баланс:
$$\text{Wall Power (AC)} = \frac{P_{\text{CPU}} + P_{\text{GPU}} + P_{\text{RAM}} + P_{\text{NVMe}} + P_{\text{Motherboard/VRM/Fans}}}{\eta_{\text{PSU}}}$$
Підтримуються сертифікати блоків живлення **80+ Titanium (94%)**, **80+ Platinum (92%)**, **80+ Gold (90%)**, **80+ Silver (88%)**, **80+ Bronze (85%)**, **80+ White (80%)**.

### 3. 🌐 Автооновлення тарифів на електроенергію та курсів валют з Інтернету
Застосунок автоматично підключається до публічних API та оновлює актуальні дані (з локальним кешем для офлайн-роботи):
- **Тарифи України (Minfin / НКРЕКП / YASNO Live)**:
  - `ua_two_zone` — **Двозонний лічильник (День / Ніч -50%)**: автоматично перемикає тариф залежно від часу доби (`07:00–23:00` → **4.32 ₴/кВт·год**, `23:00–07:00` → **2.16 ₴/кВт·год**).
  - `ua_single` — Однозонний фіксований тариф (**4.32 ₴/кВт·год**).
  - `ua_three_zone` — **Тризонний лічильник**: Пік `1.5x` (**6.48 ₴**), Напівпік `1.0x` (**4.32 ₴**), Ніч `0.4x` (**1.728 ₴**).
  - `ua_heating` — Тариф електроопалення (**2.64 ₴** вдень / **1.32 ₴** вночі).
  - `ua_commercial` — Комерційний тариф для серверних і хостингу.
- **Спотові ціни ЄС ENTSO-E (`Energy-Charts API`)**:
  - `eu_spot_pl` (Польща) та `eu_spot_de` (Німеччина/Люксембург) — живі погодинні ціни в `EUR/MWh` з конвертацією у `₴/кВт·год` та `$/кВт·год`.
- **Офіційні курси валют НБУ (`bank.gov.ua` + `Open-ER API`)**: живий курс `USD/UAH`, `EUR/UAH`, `PLN/UAH`.
- **Крипто та GPU Compute індекси (`Binance Spot API`)**: живі котирування `BTC`, `ETH`, `SOL`, `RENDER`.

### 4. 💰 Режим Майнінгу та Здачі ПК в оренду як сервера
Спеціальний режим для оцінки заробітку на платформах **Vast.ai, RunPod, Render Network, Salad, NiceHash** або при здачі ПК як виділеного сервера:
- Розраховує **валовий дохід**, **витрати на електрику** та **чистий прибуток (`Net Profit`)** за годину, добу (з урахуванням 16 год денного + 8 год нічного тарифу!) та 30 днів.
- Показує **частку електрики у доході (`%`)**, **точку беззбитковості за тарифом (`₴/кВт·год`)** та **мінімальну рентабельну ціну оренди (`$/год`)**.
- **Симулятор 5 сценаріїв навантаження**: порівнює поточний стан ПК, простій (Idle), CPU/VPS сервер, AI-інференс (75% Eco Power Limit) та 100% навантаження (24/7 проти роботи лише в нічний тариф 23:00–07:00).
- **SQLite база даних (`~/.telemetria/telemetry.db`)**: зберігає всі сесії, сумарно спожиті Вт·год / кВт·год, витрачені кошти та чистий прибуток з експортом у `CSV` та `JSON`.

## 🚀 Встановлення

**Вимоги:** Python 3.11+

```bash
git clone https://github.com/Galactic717/telemetria.git
cd telemetria
pip install -e .
```

Після встановлення в терміналі доступні команди `telemetria` та коротка команда `tlm`.

## 💻 Використання (CLI Команди)

### 1. Живий інтерактивний TUI Дашборд (за замовчуванням)
```bash
telemetria
# або з налаштуванням інтервалу оновлення:
telemetria dashboard --interval 1.0
# зробити один кадр дашборду та вийти:
telemetria dashboard --once
```

### 2. Миттєвий знімок стану системи та витрат (`status`)
```bash
telemetria status
# Вивід у форматі JSON для скриптів або автоматизації:
telemetria status --json
```

### 3. Перегляд та автооновлення тарифів на електроенергію з інтернету (`tariffs`)
```bash
# Оновити ціни та курси валют з інтернету і показати таблицю тарифів:
telemetria tariffs --refresh

# Перемкнути на двозонний лічильник (День 4.32 ₴ / Ніч 2.16 ₴):
telemetria tariffs --set ua_two_zone

# Перемкнути на тризонний лічильник або європейський спот Польщі:
telemetria tariffs --set ua_three_zone
telemetria tariffs --set eu_spot_pl

# Задати власний кастомний тариф (напр. 5.00 грн/кВт·год):
telemetria tariffs --custom-rate 5.00
```

### 4. Калькулятор та режим Майнінгу / Оренди Сервера (`mining`)
```bash
# Запустити симуляцію рентабельності для поточного ПК:
telemetria mining

# Встановити профіль Vast.ai / RunPod та ставку оренди $0.45/год:
telemetria mining --profile vastai_rtx5080 --rate-usd 0.45

# Або задати дохід у гривнях за годину (напр. 20 грн/год):
telemetria mining --rate-uah 20.0
```

### 5. Історія споживання та фінансовий звіт (`history` та `export`)
```bash
# Переглянути сумарну статистику за всі сесії (кВт·год, грн, чистий дохід):
telemetria history

# Експортувати звіт у CSV або JSON:
telemetria export --format csv --output energy_report.csv
telemetria export --format json --output energy_report.json
```

### 6. Налаштування блоку живлення та системи (`config`)
```bash
# Вказати сертифікат блоку живлення (80+ Titanium, 80+ Platinum, 80+ Gold, 80+ Bronze):
telemetria config --psu "80+ Gold" --mobo-watts 22
```

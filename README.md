## 🚀 Чому Rust Native v2.0? (Архітектурні оптимізації та продуктивність)

Весь проект повністю переписаний на **Rust (`ratatui` + `crossterm` + `nvml-wrapper` + `sysinfo` + `ureq`)**, що дало кардинальний приріст швидкодії та точності:
1. **Прямий C-ABI FFI доступ до `nvml.dll` / `libnvidia-ml.so` (`nvml-wrapper`)**:
   - Опитування відеокарти (температура, споживання у міліватах, частоти, VRAM, швидкість шини **PCIe TX/RX у MB/s**, апаратний лічильник кВт·год, активні процеси) займає **~300–1200 мікросекунд (`< 1.2 мс`)** без запуску дочірніх процесів.
2. **Паралельне та неблокуюче фонове автооновлення з Інтернету (`std::thread::scope` + Background Worker)**:
   - Всі 4 мережеві джерела (**НБУ + Open-ER**, **Тарифи України Minfin / YASNO**, **Європейський спот ENTSO-E Energy-Charts PL & DE-LU**, **Binance Spot API для BTC/ETH/SOL/RENDER**) опитуються **одночасно у паралельних потоках** та автоматично оновлюються у фоновому потоці кожні 45 секунд без жодної затримки для 60 FPS TUI інтерфейсу.
3. **Інтерактивний 3-вкладковий TUI на базі `ratatui`**:
   - Миттєве перемикання між вкладками (`[1] Дашборд ПК та Витрат`, `[2] Симулятор Оренди Сервера & Майнінгу`, `[3] Живі Тарифи з Інтернету & Історія Сесій`) та гарячі клавіші (`t`, `m`, `+`, `-`, `p`, `r`, `x`) прямо під час живого моніторингу.
4. **Вбудований бенчмарк сенсорів (`telemetria benchmark`)**:
   - Дозволяє виміряти реальну затримку опитування сенсорів ПК у мікросекундах (`µs`).

## ✨ Ключові можливості

### 1. 🖥 Реальна апаратна телеметрія комплектуючих ПК
- **Процесор (CPU)**: модель (через реєстр Windows SMBIOS / `/proc/cpuinfo`), загальне та потокове завантаження всіх ядер (`%`), жива частота кожного ядра та піковий буст (`MHz`), температура (`°C`), динамічне споживання пакету (`W` та `% від TDP`). Калібровані профілі для **AMD Ryzen 7 7800X3D / 9800X3D / 7950X** та **Intel Core**.
- **Відеокарта (GPU)**: прямий FFI доступ до **NVIDIA NVML**:
  - Температура ядра (`°C`), оберти кулерів (`%`, детекція *Zero-RPM Fan Stop*),
  - Реальне споживання у Ватах з точністю до сотих часток Вата (`W` / `Limit W`),
  - Апаратний лічильник спожитої енергії GPU (`Total Energy Consumption` у кВт·год),
  - Завантаження ядра та контролера пам'яті, зайнята/доступна **VRAM (`MiB`)**,
  - Жива пропускна здатність шини **PCIe TX / RX (`MB/s`)**, покоління та ширина лінку (`PCIe Gen xWidth`), стан `P0`–`P8`.
- **Оперативна пам'ять (RAM)**: зайнята/доступна ОЗП та Swap, автоматичне визначення фізичних модулів DIMM (кількість планок, тип `DDR5`/`DDR4`, частота `MT/s`, парт-номер) і розрахунок споживання у Ватах.
- **Накопичувачі (NVMe / SSD)**: модель фізичного диска, статус здоров'я (`Healthy`), зайнятий простір розділів, реальна швидкість читання/запису (`Read / Write MB/s`) та потужність (`W`).
- **Мережа (Network)**: активний інтерфейс, поточна швидкість завантаження та відвантаження (`↓↑ MB/s`), сумарний трафік (`GB`).
- **Топ енергоємних процесів**: ранжування процесів ОС за розрахунковим споживанням енергії (`W`) та їхньою вартістю у гривнях на добу (`₴/доба`).

### 2. 🔌 Моделювання споживання з розетки (AC Wall Power)
Розраховує повну потужність, яку ПК споживає безпосередньо з електромережі 220V:
$$\text{Wall Power (AC)} = \frac{P_{\text{CPU}} + P_{\text{GPU}} + P_{\text{RAM}} + P_{\text{NVMe}} + P_{\text{Motherboard/VRM/Fans}}}{\eta_{\text{PSU}}}$$
Підтримуються сертифікати блоків живлення **80+ Titanium (94%)**, **80+ Platinum (92%)**, **80+ Gold (90%)**, **80+ Silver (88%)**, **80+ Bronze (85%)**, **80+ White (80%)**.

### 3. 🌐 Автооновлення тарифів на електроенергію та курсів валют з Інтернету
- **Тарифи України (Minfin / НКРЕКП / YASNO Live)**:
  - `ua_two_zone` — **Двозонний лічильник (День / Ніч -50%)**: автоматично перемикає тариф за системним часом (`07:00–23:00` → **4.32 ₴/кВт·год**, `23:00–07:00` → **2.16 ₴/кВт·год**).
  - `ua_single` — Однозонний фіксований тариф (**4.32 ₴/кВт·год**).
  - `ua_three_zone` — **Тризонний лічильник**: Пік `1.5x` (**6.48 ₴**), Напівпік `1.0x` (**4.32 ₴**), Ніч `0.4x` (**1.728 ₴**).
  - `ua_heating` — Тариф електроопалення (**2.64 ₴** вдень / **1.32 ₴** вночі).
  - `ua_commercial` — Комерційний тариф для серверних і дата-центрів.
- **Спотові ціни ЄС ENTSO-E (`Energy-Charts API`)**:
  - `eu_spot_pl` (Польща) та `eu_spot_de` (Німеччина/Люксембург) — живі біржові ціни в `EUR/MWh` з конвертацією у `₴/кВт·год` та `$/кВт·год`.
- **Офіційні курси валют НБУ (`bank.gov.ua` + `Open-ER API`)**: живий курс `USD/UAH`, `EUR/UAH`, `PLN/UAH`.
- **Крипто та GPU Compute індекси (`Binance Spot API`)**: живі котирування `BTC`, `ETH`, `SOL`, `RENDER`.

### 4. 💰 Режим Майнінгу та Здачі ПК в оренду як сервера
Для оцінки прибутковості на **Vast.ai, RunPod, Render Network, Salad, NiceHash** або при здачі ПК як виділеного сервера:
- Розраховує **валовий дохід**, **витрати на електрику** та **чистий прибуток (`Net Profit`)** за годину, добу (з урахуванням 16 год денного + 8 год нічного тарифу!) та 30 днів.
- Показує **частку електрики у доході (`%`)**, **точку беззбитковості за тарифом (`₴/кВт·год`)** та **мінімальну рентабельну ціну оренди (`$/год`)**.
- **Симулятор 5 сценаріїв навантаження**: порівнює поточний стан ПК, простій (Idle), CPU/VPS сервер, AI-інференс (75% Eco Power Limit) та 100% навантаження (24/7 проти роботи лише в нічний тариф 23:00–07:00).

## 🛠 Збірка та встановлення (Rust / Cargo)

```bash
git clone https://github.com/Galactic717/telemetria.git
cd telemetria
cargo build --release
cargo install --path .
```

Після встановлення доступні нативні бінарні файли `telemetria` та коротка команда `tlm`.

## ⌨️ Гарячі клавіші в інтерактивному TUI (`telemetria`)

| Клавіша | Дія в реальному часі |
| :---: | :--- |
| `1` / `2` / `3` або `Tab` | Перемикання вкладок: **Дашборд ПК** ↔ **Симулятор Оренди/Майнінгу** ↔ **Тарифи & Історія** |
| `t` | Циклічна зміна тарифного профілю (`ua_two_zone` ↔ `ua_single` ↔ `ua_three_zone` ↔ `eu_spot_pl` ...) |
| `m` | Циклічна зміна профілю оренди сервера / майнінгу (`Vast.ai RTX 5080` ↔ `Render` ↔ `Salad` ↔ `NiceHash` ...) |
| `+` / `-` | Збільшити / зменшити ставку доходу від оренди (`+$0.02/год` / `-$0.02/год`) з миттєвим перерахунком ROI |
| `p` | Змінити сертифікат ККД блоку живлення (`80+ Titanium` ↔ `80+ Platinum` ↔ `80+ Gold` ↔ `80+ Bronze`) |
| `r` | Примусово оновити тарифи, спот ЄС, курси НБУ та кривторинок з Інтернету у фоні |
| `x` | Скинути лічильник поточної сесії (Вт·год та гривні) |
| `q` або `Esc` | Вихід з TUI |

## 💻 CLI Команди

```bash
# 1. Запуск інтерактивного 60 FPS TUI дашборду:
telemetria
telemetria dashboard --interval 0.5

# 2. Миттєвий знімок усіх комплектуючих, витрат та прибутку (текст або JSON):
telemetria status
telemetria status --json

# 3. Автооновлення тарифів на електроенергію та курсів валют з Інтернету:
telemetria tariffs --refresh
telemetria tariffs --set ua_two_zone
telemetria tariffs --custom-rate 5.00

# 4. Симулятор та калькулятор рентабельності оренди сервера / майнінгу:
telemetria mining
telemetria mining --profile vastai_rtx5080 --rate-usd 0.45
telemetria mining --rate-uah 20.0

# 5. Тест продуктивності сенсорів у реальному часі (мікросекунди на опитування):
telemetria benchmark --iterations 20

# 6. Історія сесій та експорт фінансового звіту у CSV / JSON:
telemetria history
telemetria export --format csv --output energy_report.csv
telemetria export --format json --output energy_report.json

# 7. Конфігурація блоку живлення та системи:
telemetria config --psu "80+ Gold" --mobo-watts 22
```
